# Hoy 交互改进：MyClip 0.6.4 验证记录

目标：让菜单栏浮层清楚呈现状态、最近成果和下一步；搜索不干扰采集或阅读上下文；完成验证后替换已安装版本。

## 实现范围

- 浮层改为 350 pt，56 pt 状态头像。展示助手身份、独立的采集状态、该助手的队列、最近记忆正文片段、时间和来源数量。
- 根据现有连接、授权、任务和队列状态提供连接、重试本批、恢复队列、立即整理、查看队列等入口。未改动后台队列或资料库存储格式。
- 搜索无结果、应用筛选为空、首次等待截图分别呈现；清除搜索不操作采集开关。
- 采集说明从范围、鼠标和键盘设置生成。移除时间线正文里重复的采集按钮。
- ⌘F 聚焦搜索；第一次 Esc 清除查询并恢复原文档/目录和阅读位置，第二次 Esc 离开搜索。浮层角色不参与键盘焦点；操作支持可见焦点与键盘激活。
- 新增 Debug 专用 `--preview --panel-state=...` 状态预览，使用隔离的临时资料库；正式版本不包含该状态注入入口。

## 回归依据

1. 修改前，无结果页面仍显示采集引导及“暂停采集”。修改后显示“没有找到相关截图”和“清除搜索”，结果计数与资料库总数分开。
2. 新增采集说明测试先出现 5 个断言失败，修复后 6 项采集设置测试全部通过。
3. 原版 Esc 不清空搜索；新界面已验证两级 Esc、⌘F 和文档选择恢复。
4. 长文档搜索前滚动条为 `0.4439768542872172`，清除搜索后仍为相同数值。修复前退出搜索会回到 `0`。
5. 已检查等待、整理中、完成、暂停、待确认、未连接、失败七类隔离预览；切换到 Claude 不显示 Codex 的成果，关闭浮层不取消任务，深色下状态、正文和焦点可见。
6. 键盘检查包括首焦点、Tab/Shift+Tab、跳过禁用操作、Esc 从更多菜单退回浮层再退回主窗口。最终构建已验证主操作回车打开 Memory、Shift+Tab 到最近记忆后空格打开对应 Markdown 文件。更多菜单沿用 macOS 原生键盘导航设置。
