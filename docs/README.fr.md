MyClip capture votre travail et l’organise avec l’agent IA de votre choix :

- **Memory** : des notes Markdown consultables, avec des liens vers leurs sources.
- **Timeline** : un historique des captures avec reconnaissance de texte OCR sur l’appareil.
- **Kanban** : des tâches, leur avancement et des rapports quotidiens, hebdomadaires ou mensuels.

Les captures et les notes sont enregistrées sur votre Mac. L’organisation par IA peut utiliser le service cloud de votre agent. Activez **MyClip MCP** pour que vos outils d’IA recherchent dans vos souvenirs enregistrés.

## Installation

Nécessite **macOS 13+**, **Node.js 22+** et un compte pour l’agent choisi.

1. Téléchargez le DMG Apple Silicon ou Intel depuis [Releases](https://github.com/section9-lab/MyClip/releases) et déplacez MyClip dans **Applications**.
2. Ouvrez MyClip, choisissez un agent et cliquez sur **Commencer**.
3. Accordez les autorisations **Enregistrement de l’écran** et **Accessibilité**. MyClip capture et organise automatiquement tant qu’il est ouvert.

Dans les **Réglages**, vous pouvez modifier la portée des captures, exclure des applications ou désactiver l’organisation automatique. Quittez MyClip pour arrêter les captures.

Les versions sont auto-signées et non notariées. Si macOS bloque le premier lancement, consultez l’[aide à l’installation](release-signing.md#installing-a-community-build).
