# MyClip 0.6.22

- Retry recoverable certificate, TLS and upstream internal errors with the existing bounded backoff instead of immediately stopping screenshot organization. Certificate verification remains enabled.
- Recover an enabled Agent after a transient connection failure so its failed connection state cannot permanently block dispatch.
- Automatically restore queues paused by an older build for a now-retryable error. Preserve the original Agent, batch, error, attempt count and retry deadline; respect manual pauses and the six-attempt limit.
- Keep Backstage status consistent with the queue: paused retries no longer display an active retry-attempt badge, and recoverable connection failures explain that they will retry automatically.
- Add native regression checks using real SQLite queues and ACP fixture subprocesses, including the blocked timeout retry behind a newer certificate failure.

## Validation

Local application-source compilation, Agent activation, model selection, task ingestion, failure recovery and Backstage responsiveness checks passed. The release workflow additionally runs core XCTest, cloud-sync, adapters, packaging, benchmarks and native-app tests on Apple Silicon and Intel before publishing.

This release retains serial organization and does not add in-app update detection or automatic installation.
