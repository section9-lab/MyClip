# MyClip 0.6.18

- Add **Memory → Cloud Sync** for Google Drive and Notion, with independent automatic sync, immediate sync, progress, cancellation and retry controls. Google Drive uses native Google Docs; Notion uses pages under an app-owned parent. Configure Google desktop OAuth or a Notion integration inside the app. Credentials stay in the macOS Keychain.
- Publish an overview and authored Memory pages incrementally, preserve cloud document IDs across edits and renames, and resume interrupted uploads. Daily and Inbox are optional. This is one-way publishing from MyClip; cloud edits do not write back. Removed or excluded memories move only their managed cloud copies to Trash. Original screenshots and standalone OCR files are not uploaded.
- Remove the **Rebuild Index** entry from Settings.
- Add WorkBuddy through its `codebuddy` CLI and QwenWork through its CLI or bundled desktop ACP engine. Extend Agent discovery, configuration and session actions for both.
- Keep onboarding Agent selection as a draft. **Start using** connects and enables the final selection; failed connections retain the working Agent and keep setup open for retry.
- Put discovered tasks directly into Todo, Doing or Done. Newer dated evidence can update or reopen tasks; undated evidence cannot overwrite an existing status. Upgrade legacy candidates into their suggested board columns while retaining evidence and event history.
- Fix unstable nested execution-history layout in **Backstage** and reduce redundant Agent-icon redraws and mouse-tracking updates. Preserve the five-row viewport, bounded history, accessibility and reduced-motion behavior.
- Add localized strings for the new controls and errors across the six existing translation languages.

## Validation

GitHub Actions runs core, cloud-sync, adapter, packaging, benchmark and native-app checks for Apple Silicon and Intel before publishing both DMGs. Cloud API contracts and desktop OAuth callbacks are covered with isolated fixtures; real Google Drive and Notion accounts still require user configuration and end-to-end verification.

The Backstage regression checks fail 12 checks against 0.6.16 and pass all 21 checks against the fix in both Debug and Release builds. Independent Release windows also passed actual mouse clicks, nested scrolling, filtering, details, Escape and resizing. The full long-running freeze was not deterministically reproduced; the fix removes the unstable layout and native-view invalidation paths identified during diagnosis.

The task database upgrades to schema 16. Back up the library before updating if you need to return to an older version.
