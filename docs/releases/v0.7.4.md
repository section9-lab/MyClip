# MyClip 0.7.4

## Prompts as files, and Chinese MCP guidance

- Every generation and recall prompt now lives as Markdown under `Prompts/`, with two JSON files for the MCP tool schemas. The batch, digest, dream, patrol, weekly, cold-start, task and handoff texts are unchanged; only where they are stored moved.
- The MCP instructions, tool descriptions and parameter descriptions are now Chinese, matching the app. Tool names, enum values and schema shapes are unchanged, so existing clients keep working.
- There is no prompt settings page. Editing a prompt is a source change followed by a build, not a runtime override.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, agent preferences, and calendar events are preserved.

## Validation

Core tests cover the rendered default prompts, the shared Markdown blocks and placeholders, the MCP instructions and tool schemas, the handoff line templates, and the existing Memory and queue behaviour. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.

## Downloads

- **Apple Silicon:** `MyClip-0.7.4-arm64.dmg`
- **Intel:** `MyClip-0.7.4-x86_64.dmg`
