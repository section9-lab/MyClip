# MyClip 0.6.36

## Memory stays readable when a page is malformed

- Stop a duplicated Memory ID from emptying the whole library. The established path keeps its identity, and every other copy is assigned a new one before indexing.
- Mark remaining duplicate files as unindexed instead of failing the entire Memory refresh.
- Show unindexed Memory files in the Memory view with their paths and reasons, plus a shortcut to the Memory folder.
- Show library and runtime failures in the main window with a retry action instead of leaving an unexplained empty pane.
- Repair the affected pages in existing libraries automatically on the next refresh; their Markdown content stays on disk.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

The core tests cover duplicate-ID repair and stable identity for the established path. Native-app and performance checks confirm the Memory list, Backstage and the main run loop stay responsive. The release workflow tests, signs and packages both Apple Silicon and Intel builds.
