# MyClip 0.6.13

- Add **Backstage**: one page showing which Agent organizes your captures, how the queue is doing, what each batch did and what it cost.
- Keep the library usable when a Memory file is invalid. Files over the 128 KB body cap, empty files and files with broken metadata are skipped and keep their last good index instead of blocking search, MCP and organizing.
- Hand cap problems to the Agent, never to the user. A file the Agent leaves invalid goes back to its previous revision, the batch reruns automatically with the reason in its prompt, and once retries are used up the instruction moves into the next handoff. Pages over 96 KB get a mandatory "organize first, then split" instruction before anything is appended.
- Define a fixed project page structure (overview, current status, confirmed decisions, key background, related records) with one fact per bullet and compact citations; the reader shows 8-character source IDs while files keep full IDs.
- Retry transient Agent failures such as timeouts, dropped connections and overloaded providers automatically with backoff instead of pausing the queue.
- Rank memory search across several queries and expand one hop along Wikilinks; MCP results carry related memories with the passage that links them.
- Record token usage per day with the share served from cache and a like-for-like comparison with the previous period.
- Skip near-duplicate screenshots with a block-level perceptual hash and a short per-window cooldown.
- Launch Agents with the hosting session's environment variables removed, so Claude Code authenticates the way it does in your terminal.
- Add Cursor and OpenCode icons.
