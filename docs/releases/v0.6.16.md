# MyClip 0.6.16

- Open the correct macOS privacy pane for Screen Recording, Accessibility, and Files & Folders from onboarding. Previously, Screen Recording could open the Accessibility pane on newer macOS versions.
- Make each permission control open its corresponding settings pane even when the permission is already granted. Accessibility also opens its settings pane when macOS no longer shows a request prompt.

## Validation

The three routes were checked against System Settings on macOS 27, and the full local test suite passed. GitHub Actions also runs the full test suite for both architectures before publishing.

## Downloads

- **Apple Silicon:** `MyClip-0.6.16-arm64.dmg`
- **Intel:** `MyClip-0.6.16-x86_64.dmg`
- **Public signing certificate:** `MyClip-signing-certificate.pem` (for verification; no installation required)
- Verify downloaded files against `SHA256SUMS`.

Requires macOS 13 or later. The builds use the same project-only community signing certificate as 0.6.15 and are not notarized. See [release signing and permission recovery](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md) for first-opening and authorization guidance.
