# MyClip 0.6.30

## A clearer, more native usage chart

- Redesign Token Usage around the macOS chart guidance and familiar Apple Health-style hierarchy: range selection, a prominent period total, date context, a restrained single-series bar chart, and subtle axes and grid lines.
- Replace the crowded per-Agent stacked bars with one truthful daily or weekly total. Zero-usage dates remain visible, so sparse activity is not visually compressed into a misleading continuous run.
- Add pointer inspection with a selected-date rule and exact Token/request details, while keeping the layout stable as the pointer moves.
- Keep Agent totals as a labeled textual breakdown instead of requiring people to decode six chart colors.

## Token composition and accessibility

- Present input, output, cache-read, and cache-write usage as a Storage-style segmented bar with exact values and percentages below it.
- Pair color with labels and distinct SF Symbols, use adaptive system colors, and support both light and dark appearances.
- Add an accessibility chart descriptor for VoiceOver and Audio Graphs, preserve the data-table alternative, and provide explicit empty states instead of estimating missing provider data.
- Improve responsive behavior for narrow windows while preserving the 7-day, 30-day, and all-time ranges.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, capture settings, and Agent preferences are preserved.

## Validation

Local checks covered all six Agents, 7-day, 30-day and all-time ranges, chart/table switching, zero Token values, requests without reported usage, empty history, light and dark appearances, minimum-width layouts, visibility-aware loading, and the full native performance suite. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.
