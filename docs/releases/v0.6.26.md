# MyClip 0.6.26

## Lower background CPU usage

- Fix repeated Backstage layout work, remove continuous status animations and stop status clocks when their particular window is hidden, minimized, occluded or inactive. Keep execution history geometry stable at narrow widths.
- Refresh screenshots, Memory, the independent task board, statistics and token usage only when their data changes. Coalesce concurrent refresh requests and avoid publishing identical permissions or streaming status text, while preserving agent liveness tracking.
- Cache Markdown reads, parsing, hashes, image-directory capacity and content-dependent Memory checks. Observe filesystem changes and independent SQLite connections; retain immediate checks for explicit Memory reads and a periodic reconciliation fallback.
- Preserve sensitive-data, provenance and time-dependent checks. A broken Memory file does not prevent the independent task board from refreshing.
- Defer automatic Memory maintenance in Low Power Mode or under thermal pressure, pace background OCR in Low Power Mode and delay it under serious thermal pressure. Keep screenshot trigger rules, manual actions, retention cleanup and failure recovery intact. Suspend input polling while the screen is locked or asleep.

Short synthetic tests with the same 50-record fixture showed the old Backstage at about 37% CPU and the updated surface at about 2–6% while visible and 0.1–0.2% while hidden. Repeated Memory checks reused cached work without changing findings. These are CPU microbenchmarks, not a promise of proportional whole-device energy or battery-life improvements. See [performance and energy](https://github.com/section9-lab/MyClip/blob/main/docs/performance-and-energy.md) for methodology and limits.

## Retire the Memory Inbox

- Stop creating `Inbox/`, pending-memory notes and inferred Profile candidates. Pending work and task status belong to the independent board rather than a second Memory queue.
- Remove Inbox-specific presentation and cloud-sync controls. Preserve existing nonempty Inbox folders, notes and links for compatibility; safely remove empty folders and update only untouched overview templates.
- Legacy Inbox notes stay local and are not automatically promoted to confirmed knowledge or board tasks. Previously managed Inbox cloud copies are moved to the remote trash on the next sync; original local notes are retained.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…**. Confirm the update to download, verify, install and relaunch. Existing screenshots, authored Memory, task-board data, preferences and signing identity are preserved.

Versions **0.6.23 and earlier** need one manual installation to acquire the updater.

## Validation

Local checks covered performance and cache invalidation, independent board updates, external file edits, agent recovery and switching, task-ingestion recovery, capture lifecycle, the menu-bar board, cloud sync and 13 benchmark tests. The release workflow runs the full core, adapter, packaging, benchmark, native-app and signed-update checks on Apple Silicon and Intel before publication.
