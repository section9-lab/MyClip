# MyClip 0.6.27

> Not published: release validation found a native test-fixture compilation issue. Superseded by 0.6.28; no update assets were published for this tag.

## A clearer Auto-organize workspace

- Replace Backstage with **Auto-organize**, containing three independent pages: **Status**, **Execution history**, and **Usage**. Status is the default; only the current page is mounted.
- Keep the current Agent, model, progress, elapsed time, pending captures and queue controls on Status. Move Agent selection, accounts, connections and setup into **Agents & Accounts**.
- Give execution history its own native scrolling list with Agent, status and local-date filters. Load 50 records at a time, including older records beyond the recent library snapshot. Refresh older jobs without dropping already loaded pages.
- Put actual Memory changes and source captures first in execution details. Keep technical steps and token details collapsed by default, and read per-run usage without loading the global dashboard.
- Give usage its own chart/table page with 7-day, 30-day and all-time ranges. Aggregate only while the page and its window are visible, catch up on return, and handle cancelled/concurrent refreshes without losing an update. Report missing Agent usage explicitly rather than treating it as zero or a complete bill.

## Fixes

- Fix the token chart crash when WorkBuddy or Qwen Work reports usage. Keep a stable color domain for all six Agents, including when data changes while the chart is visible.
- Avoid repeated date labels for single-day usage charts.
- Stop empty dispatcher checks from publishing false busy/idle transitions. Preserve execution reservations, action guards, Agent switching, cancellation and recovery behavior.

Screenshot quality, capture triggers, historical screenshots, authored Memory, links and independent task-board data are preserved. These changes do not establish a whole-device battery-life improvement or resolve all capture/OCR/Agent startup peaks.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install and relaunch. Existing data, preferences and signing identity are preserved. Versions **0.6.23 and earlier** need one manual installation to acquire the updater.

## Validation

Local checks covered the complete idle dispatcher, independent board updates, real Charts rendering for all six Agents, chart/table switching, missing and zero usage, 105-record SQLite history pagination and filters, older-job updates, execution-detail rendering, visibility-aware loading, cancelled/concurrent refreshes, narrow layouts, and Agent activation, models, recovery, switching and task-ingestion recovery. Fixtures use temporary libraries and do not call paid models.

The release workflow runs the full core, adapter, packaging, benchmark, native-app and signed-update checks on Apple Silicon and Intel before publication. Short synthetic CPU measurements are not battery-life measurements.
