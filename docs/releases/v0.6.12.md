# MyClip 0.6.12

- Always show **Get Started** in onboarding. The button stays disabled until Screen Recording and Accessibility are granted and Agent selection finishes. Permission status continues to update automatically.
- Add an eight-second recording of native onboarding to the beginning of the README demo, preserving the existing Memory, Timeline, Kanban, and Reports demonstrations.
- Update the demo descriptions in English, Simplified Chinese, Spanish, French, German, Japanese, and Korean.

## Downloads

- **Apple Silicon:** `MyClip-0.6.12-arm64.dmg`
- **Intel:** `MyClip-0.6.12-x86_64.dmg`
- **Public signing certificate:** `MyClip-signing-certificate.pem` (for verification; no installation required)
- Verify downloaded files against `SHA256SUMS`.

Requires macOS 13 or later. Both builds use the same project-only community signing certificate as 0.6.11. These are self-signed builds and are not notarized. See [release signing and permission recovery](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md) for first-opening and authorization guidance.
