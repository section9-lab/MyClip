# MyClip 0.6.38

## Backstage keeps its English name

- Show **Backstage** in the sidebar and window title again, alongside **Memory**, **Timeline** and **Kanban**, instead of translating the page name to the interface language.
- Keep the page's section labels, activity rows and everything else localized as before.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

The native app builds and the sidebar, window title and Backstage header all use the page's English name. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.

## Downloads

- **Apple Silicon:** `MyClip-0.6.38-arm64.dmg`
- **Intel:** `MyClip-0.6.38-x86_64.dmg`
- Verify downloads against `SHA256SUMS` and the persistent community signing certificate.

Requires macOS 13 or later. See [in-app updates](https://github.com/section9-lab/MyClip/blob/main/docs/app-updates.md) and [release signing](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md).
