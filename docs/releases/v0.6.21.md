# MyClip 0.6.21

- Connect **WorkBuddy** and **QwenWork** product accounts for ACP-based image and text Memory generation. Authorize each user's own account in the browser, load that account's live models and allowance, and run real file-reading, editing and command tools before validating and importing Markdown. MCP recall remains a separate feature.
- Automatically prepare and verify the required runtime on first connection. No preinstalled Node, npm, OpenCode, vendor desktop application or CLI is required for these two account connections. Use official Apple Silicon and Intel baseline distributions, retain their licenses, and support reuse, interrupted-download retry and damaged-component recovery.
- Keep account credentials in the system Keychain, scoped to the product and library. Isolate executor configuration and unrelated provider credentials. Support authorization cancellation, reauthorization and allowance refresh. Use MyClip-owned protocol adapters; no Magpie application, gateway or plugin is required.
- Improve Codex desktop-engine discovery, including renamed applications and nested executables. Prevent connector dependencies from shadowing the desktop engine. Preserve structured ACP session failures instead of reporting a refused upstream request as successful.
- Persist task ingestion independently of successful Memory writes. Preserve valid candidates when another candidate fails, validate screenshot/Memory provenance, and recover interrupted or historical task stages with bounded retries and visible recovery status.
- Make task reports reflect evidence within the selected reporting period. Keep future plans empty until explicitly edited and preserve concrete edits when cleaning older generated placeholders.
- Match menu bar Kanban colors to the application board, reduce its width and hide scroll indicators while retaining independent column scrolling. Translate the new controls into the existing languages.

- Include package resource bundles beside standalone native test executables, matching the installed app layout. This fixes the missing-resource crash found by the 0.6.20 release gate; 0.6.20 was not published.

## Validation

GitHub Actions tests core, cloud-sync, protocol adapters, managed-runtime installation, packaging, benchmarks and native-app behavior on Apple Silicon and Intel before publishing the two DMGs. Task-recovery checks are included in the native-app release gate.

Local verification used isolated libraries and synthetic images with random reference numbers present only in image pixels. WorkBuddy and QwenWork both completed initial generation and incremental Markdown editing with source association and ingestion. An additional check used real downloaded components in a clean user profile with simulated accounts/upstreams; both ACP tool loops wrote Markdown without preinstalled Agent tools.

These checks do not establish support for every account, organization, model or future vendor protocol. Each user must authorize their own product account; MyClip does not decrypt desktop credentials or control an existing desktop conversation. Local real-account tests ran on Apple Silicon; Intel execution is checked by the release workflow.
