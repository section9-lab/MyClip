# MyClip 0.6.37

## Compact tool activity and a quieter menu bar

- Show the menu bar item as a monochrome paperclip template icon, so it follows the menu bar appearance in light and dark mode instead of standing out as a full-colour tile. Capture state stays in the tooltip and accessibility description.
- Keep each tool call to one live-activity row: the tool label and the command it runs now share a line, so a command no longer adds a second row or pushes an older one out.
- Trim tool rows to a single line and show the full text in a tooltip; streamed replies keep their three-line preview.
- Restore any missing Memory layout folder (`Wiki/*`, `Daily/`) on refresh, while root documents are seeded only once and custom folders are never recreated.
- Drop the retired Inbox compatibility layer: Memory no longer cleans up, upgrades or migrates an `Inbox/` directory.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

The core suite covers Memory layout, link and cloud-sync behavior, and the ACP client keeps a bare tool label beside the command that follows it. Native-app checks cover live activity grouping, cancellation and agent switching. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.
