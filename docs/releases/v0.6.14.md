# MyClip 0.6.14

- Improve Memory recall with paragraph ranking, page aliases and two-hop Wikilink traversal. Search results include concise snippets, source references, event times and the links behind a match.
- Simplify the read-only MCP interface to `memory_search` and `memory_get`, replacing the previous memory tools. Read individual sections or line ranges and follow links and backlinks from the returned pages.
- Add daily Memory consolidation while idle, including page reviews, recurring patrols and weekly summaries. **Dream Now** can start a review manually.
- Seed an empty Memory library from supported text documents in Desktop and Documents, subject to macOS folder permissions.
- Add Simplified Chinese, English, Japanese, Korean, Spanish, French and German interfaces, with language selection during onboarding and Memory output following the selected language.
- Share formatted task reports by copying them and opening a supported destination, including Gmail, Notion, Feishu, Lark, DingTalk, WeCom, WeChat and Slack when available.
- Reorganize application code and tests by responsibility, centralize application prompts in five Swift files under `MyClip/Core/Prompt`, and archive inactive Kara sources separately.
- Consolidate local and CI checks under `Scripts/test.sh`. Package benchmark tools, prompts, tests and reports together while keeping datasets, credentials and generated results local.

## Validation

The complete local test command passed: 337 core tests with 9 opt-in tests skipped, adapter and packaging tests, 13 benchmark tests and all 7 native application suites. Refactoring preserved generated prompts and retrieval results for the 199-question comparison, excluding timing measurements.
