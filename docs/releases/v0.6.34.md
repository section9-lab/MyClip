# MyClip 0.6.34

## Automatic organization overview

- Follow captures, the pending queue, the selected Agent and Markdown memory in a new organization flow. Movement responds to actual capture, batch and memory-writing events, and respects Reduce Motion.
- Open Agent and account settings from the flow, and find organization rules using the help button.
- See the latest four execution, thinking and response updates in the status window, with streamed replies updated as they arrive.
- Improve compatibility with newer Swift compilers when building Memory search.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

The release workflow tests, signs and packages both Apple Silicon and Intel builds. The organization overview includes responsiveness, layout, streamed-activity and performance regression checks. Real Agent services and interactive animation still require validation with your own setup.

- **Intel:** `MyClip-0.6.34-x86_64.dmg`
