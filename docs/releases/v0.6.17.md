# MyClip 0.6.17

- Detect OpenCode and other Agent command lines installed through nvm, including when MyClip is opened from Finder with a minimal system PATH.
- Preserve command locations inherited from the launching environment and support a custom `NVM_DIR`. When no shell-selected version is available, check installed nvm versions from newest to oldest.
- Use the same search paths when launching Agents and installing connection components so npm commands can find Node.js. Remove duplicate PATH entries while keeping MyClip's local connection components first.

## Validation

Regression checks cover Finder-style discovery, numeric Node version ordering, inherited PATH precedence, custom nvm locations, Node.js resolution during launch, and explicit path overrides. GitHub Actions runs the full test suite for Apple Silicon and Intel before publishing.

## Downloads

- **Apple Silicon:** `MyClip-0.6.17-arm64.dmg`
- **Intel:** `MyClip-0.6.17-x86_64.dmg`

Requires macOS 13 or later. The builds use the existing project-only community signing certificate and are not notarized. See [release signing and permission recovery](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md) for first-opening and authorization guidance.
