# MyClip 0.6.24

- Add native in-app updates with Sparkle. Use **MyClip → Check for Updates…** or **Settings → About MyClip → Check for Updates…**. Automatic checks run daily and can be disabled in Settings. Installing an update requires confirmation, verifies its signature, replaces the application and relaunches it while preserving your library and preferences.
- Publish separate signed update feeds for Apple Silicon and Intel. Releases become visible only after both DMGs, signed feeds, the signing certificate and checksums have been uploaded successfully.
- Show the Memory files actually saved by each new organization batch or dream, including changes made through shell commands. Open a saved file directly from its execution details. Read-only runs and older records without saved-file results are identified explicitly; rejected writes are excluded and valid writes survive retries.
- Prefer the current saved Memory document over stale search results when opening a memory.
- Add anonymous app-launch and daily-activity analytics, with a **Share anonymous usage** switch in Settings. Screenshots, clipboard contents, Memory text and conversations are not included.

## First installation of the updater

**Versions 0.6.23 and earlier need one manual installation of 0.6.24.** They do not contain the updater. After installing this release, future versions can be checked, downloaded and installed from MyClip itself.

## Validation

Apple Silicon and Intel checks passed for native builds, Memory navigation, updater lifecycle, signed update feeds and 37 Memory persistence and execution-record regressions. The release workflow additionally runs the full core, cloud-sync, adapter, packaging, benchmark and native app suites on both architectures before publishing.
