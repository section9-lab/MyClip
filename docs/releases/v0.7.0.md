# MyClip 0.7.0

## A calendar for dated commitments

- Add **Calendar** below Kanban. Day, Week and Month views share the same local library, and the default is Week.
- Replace the small system date picker with a 300 pt month rail: larger day cells, event dots by kind, a blue ring for today, a selected-day agenda with start and end times, and muted adjacent months.
- The Week view gives every day a column, with a pinned all-day band, an hour grid that expands to early or late events, and a red current-time line. Overlapping events stack with a 12 pt offset so their titles stay readable in narrow columns.
- The Month view uses a full-page seven-column grid. Each day shows up to three events, the remainder as “还有 N 项”, and a right-click creates an event on that day.
- AI events come from two places: dated `<!-- myclip-event -->` passages in Memory, and explicit `calendar_add` writes from the hourly digest. Both are idempotent per occurrence and cite their Memory page and source line.
- Manual events and edits sit beside AI events. Editing pins the event, so later Memory projection does not revert it; removing keeps a dismissal marker, so the agent cannot silently add it back.
- The same write-only MCP surface can maintain the Kanban board (`board_*`) and the calendar (`calendar_*`). It is enabled only in sessions MyClip launches itself; the MCP server installed into Claude Code, Codex and OpenCode remains read-only.
- Memory writes are split into a daily batch pipeline and an hourly digest. The digest reads changed Daily pages and updates Wiki, Memory, Now, Profile, the board and the calendar without re-reading the whole vault.
- Keep the native macOS behavior: system blue, SF Symbols, system separators, light and dark appearance, keyboard-focusable dates, and no third-party calendar library.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

Core tests cover calendar projection, idempotent replay, user edits surviving later synchronization, dismissals, all-day and daylight-saving boundaries, week/month grids, overlap lanes, and the digest write tools. Native checks render the calendar at full and minimum widths in light and dark mode, including the compact header and the single-scroller week grid. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.
