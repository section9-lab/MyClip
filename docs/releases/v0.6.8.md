# MyClip 0.6.8

- Redesign onboarding with permission controls and default Agent selection beside an original futuristic oil painting.
- Detect installed Codex and Claude Code runtimes, including the CLI bundled inside a renamed Codex desktop app. Connect the selected Agent before saving it as the default; preserve the previous default if connection fails.
- Keep onboarding open after authorization so users can finish Agent setup before entering the library.
- Require Apple certificate signing for packaged updates. Ad-hoc signatures can invalidate existing macOS Screen Recording and Accessibility grants; release jobs now stop if signing credentials are missing.

Release maintainers must configure the signing secrets documented in [Release signing](../release-signing.md) before publishing this version. The local repair build uses the previously authorized Apple Development identity; public distribution should use a consistent Developer ID Application identity.
