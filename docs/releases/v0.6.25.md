# MyClip 0.6.25

- Send anonymous usage events to the independent MyClip analytics project. Preserve the installation identifier while keeping event queues and daily-activity bookkeeping separate from the previous shared project.
- Include language, system country/region setting and time zone in anonymous usage events. These describe device settings rather than verified physical location. The existing anonymous-usage switch still controls reporting; screenshots, clipboard contents, Memory text and conversations are not sent.
- Refresh regional settings on each newly reported active day and avoid suppressing the first daily event after switching analytics projects.
- Update the privacy disclosure and documentation for the independent analytics board, historical reporting and daily activity by app version.
- Allow native application checks to be run manually through GitHub Actions.

This release retains signed in-app updates and the saved Memory-file results introduced in 0.6.24.

## Updating

From **0.6.24**, use **MyClip → Check for Updates…**. Confirm the update to download, verify, install and relaunch. Existing screenshots, Memory files, preferences and signing identity are preserved.

Versions **0.6.23 and earlier** need one manual installation to acquire the updater.

## Validation

The analytics checks cover 11 scenarios, including daily/restart deduplication, opt-out, project migration, ambiguous regional settings and language/timezone disagreement. The release workflow runs the full core, cloud-sync, adapter, packaging, benchmark, native UI and signed-update checks on Apple Silicon and Intel before publishing.

## Downloads

- **Apple Silicon:** `MyClip-0.6.25-arm64.dmg`
- **Intel:** `MyClip-0.6.25-x86_64.dmg`
- Verify downloaded files against `SHA256SUMS` and the persistent community signing certificate.

Requires macOS 13 or later. See [in-app updates](https://github.com/section9-lab/MyClip/blob/main/docs/app-updates.md) and [release signing](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md).
