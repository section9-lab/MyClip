# MyClip 0.6.19

- Add searchable **Model** selection to every Agent card in **Backstage**: Codex, Claude Code, OpenCode, Cursor, WorkBuddy and QwenWork. Fetch model IDs and names from each Agent's live session catalog, without a bundled model list. Support current ACP config options, grouped options, configuration updates and legacy model selectors.
- Save confirmed model choices separately for each Agent and reapply them to new organization sessions. **Follow Agent default** clears that Agent's override. Switching is disabled during work; failed or unavailable choices retain the saved preference instead of silently falling back.
- Show image support when it can be verified, including exact-ID capability metadata from OpenCode's local catalog. Mark undeclared capabilities as unknown. Disable known text-only choices and reject screenshot batches before submitting images when the current model is known to lack image support.
- Replace the menu bar's immediate application-opening action with a read-only Kanban popover. Browse Todo, Doing and Done in independently scrolling columns, with compact layouts, update timestamps, loading, empty and error states. **Open Application** and **Quit Application** remain explicit footer actions. Include vendored Lucide icons and their license notice.
- Enable both **similar-image deduplication** and **near-uniform-image filtering** by default when no filter choice has been saved. Preserve existing explicit choices, including disabled filters. Change the downward-scroll idle trigger from three to five seconds and update status text and translations.
- Simplify the multilingual introduction and installation guides, document model selection, and translate the new controls into the six existing translation languages.

## Validation

GitHub Actions runs core, cloud-sync, adapter, packaging, benchmark and native-app checks on both Apple Silicon and Intel before publishing either DMG. New checks cover all six Agent connection paths with fixture subprocesses, model persistence and recovery, image capability blocking, searchable native model lists, and the menu bar's read-only interactions. Backstage responsiveness checks remain part of the release gate.

Protocol fixtures do not establish that all six providers' real accounts and models have passed end-to-end verification. The installed OpenCode model catalog was checked without sending a prompt. Models and account availability remain controlled by each Agent and service. This release does not claim that every unknown model supports images or that the previously observed intermittent freeze can never recur.
