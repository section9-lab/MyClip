# MyClip 0.6.15

- Send the original screenshot to the organizing Agent for every capture trigger. Batches contain up to eight screenshots; OCR remains a local text document and search source, not an Agent input.
- Keep screenshot details focused on the original image and raw OCR. Remove the experimental structured Markdown preview and clean up its old sidecar files when the library opens.
- Improve mouse capture controls and filter screenshots with near-total background coverage. Repair a missing image file when a repeated capture can supply it.
- Refine onboarding, Backstage, task board, report sharing, and library controls.

## Validation

Local checks passed: 366 core tests (10 skipped), adapter and packaging tests, 51 benchmark tests, and all seven native application suites. The mouse-capture integration check verifies that the Agent receives an image attachment.
