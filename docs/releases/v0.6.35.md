# MyClip 0.6.35

## Steadier menu bar and quieter failures

- Keep the MyClip application icon in the menu bar instead of switching it between recording, paused and permission symbols. Capture state remains available in the tooltip and accessibility description.
- Stop runtime failures from opening a global “MyClip / OK” alert. Memory revision conflicts remain inside the editor, and background work no longer interrupts unrelated pages.
- Split the Token usage chart by Agent, with a distinct color per Agent and per-Agent details for the selected day or week.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

Local checks covered core storage and Memory behavior, cloud sync, benchmarks, the complete native app test suite except OCR document timing while this Mac was in Low Power Mode, and the performance suite including Agent-split usage charts. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.
