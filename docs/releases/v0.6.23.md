# MyClip 0.6.23

- Stop the running Agent when disabling it or selecting another Agent. A nonresponsive adapter cannot keep the queue occupied indefinitely; cooperative cancellation retains final token usage.
- Keep the old execution in history and return unfinished screenshots to the queue atomically. The newly selected Agent can resume them without another five-minute delay. Existing captures, Memory files and manual pauses are preserved.
- Hand off queued retries left with a previous Agent, including after restarting an older installation, so they cannot block the selected Agent.
- Release interrupted task repairs back to their durable queue without treating a user stop as a failed attempt.
- Add native regression coverage using real SQLite and ACP fixture subprocesses for disabling, direct switching, ignored cancellation, connection stalls, rapid switches, final usage, queued retries and interrupted repairs.

## Validation

Application-source compilation and native Agent switching, activation, model selection, failure recovery and task recovery checks passed locally. The release workflow also runs core XCTest, cloud-sync, adapter, packaging, benchmark and native UI checks on Apple Silicon and Intel before publishing.
