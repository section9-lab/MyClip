# MyClip 0.6.39

## A grouped Backstage dashboard

- Rework the Backstage status page into a grouped dashboard: a fixed page header with the section switcher, a four-step capture-to-Memory flow card, and a sticky queue footer with the primary actions.
- Show the running batch as a summary card with the Agent, its model, the source apps, the live stage and elapsed time. The activity bar indicates work without claiming a percentage that MyClip does not know.
- Replace the activity list with a table of time, tool, target and duration, filtered by tool. Rows come from persisted ACP tool calls, with the in-memory activity stream as a fallback, and the table links to the full execution history.
- Move Agent switching into the run card: change the default Agent, choose a model, or open Agent and account settings from one menu.
- Show real counts only: Memory reports the number of organized captures, the flow card shows the latest real event, and the footer shows the pending queue and the last save time.
- Keep the native dark mode, narrow-window layout, Reduce Motion support and the single-scroller rule.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

Native-app checks render the redesigned page at full and minimum content widths in light and dark mode, verify the single-scroller rule, and keep the visible and hidden CPU budgets. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.
