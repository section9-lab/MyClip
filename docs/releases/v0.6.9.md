# MyClip 0.6.9

- Redesign onboarding with native permission controls and default Agent selection beside a dreamcore courtyard oil painting, with light and dark appearances.
- Detect installed Codex and Claude Code runtimes, including the CLI bundled inside a renamed Codex desktop app. Save the selected default only after connecting successfully; preserve the previous default if connection fails.
- Keep onboarding open after authorization so users can finish Agent setup before entering the library.
- Add **Reopen Setup Guide** in Settings → About MyClip to revisit onboarding without resetting permissions, saved data, or the default Agent.
- Sign both architecture builds with one persistent, project-only community certificate, with no paid Apple Developer account required. CI pins the certificate and rejects missing or mismatched signing identities.

## Downloads

- **Apple Silicon:** `MyClip-0.6.9-arm64.dmg`
- **Intel:** `MyClip-0.6.9-x86_64.dmg`
- **Public signing certificate:** `MyClip-signing-certificate.pem` (for verification; no installation required)
- Verify downloaded files against `SHA256SUMS`.

Requires macOS 13 or later. These are self-signed community builds, not notarized Developer ID distribution builds. macOS may require **System Settings → Privacy & Security → Open Anyway** after the first opening attempt.

This release changes signing identity from older builds. Screen Recording and Accessibility may need one-time reauthorization: if an enabled permission remains unrecognized after restarting, remove only MyClip from the affected list and add `/Applications/MyClip.app` again. See [release signing and permission recovery](https://github.com/section9-lab/MyClip/blob/main/docs/release-signing.md).
