# MyClip 0.6.33

## Lower background energy use

- Start the selected Agent only when work or an explicit configuration action needs it, instead of keeping its ACP, Node, and MCP processes alive from application launch.
- Release task sessions immediately and close idle configuration sessions after 60 seconds.
- Replace the fixed three-second background loop with event-driven wakeups and deadline-aware backoff for queued jobs and retries.
- Replace the 0.15-second capture poller with one-shot trigger deadlines, reduce fallback pointer checks, and throttle accessibility focus queries.
- Limit automatic captures to 2560 pixels on the longest edge, or 2048 pixels in Low Power Mode, while keeping manual captures at up to 4096 pixels.
- Use fast Vision recognition for background OCR and defer OCR during Low Power Mode or serious thermal pressure.
- Reduce image hashing copies, memory-map OCR input, avoid directory enumeration during permission checks, and streamline pending-image database queries.

Capture behavior, searchable text, queued work, retries, and Agent switching remain compatible with existing libraries. Low Power Mode now favors battery life by delaying nonessential background recognition and maintenance until normal operation resumes.

## Updating

From **0.6.24 or later**, use **MyClip → Check for Updates…** to download, verify, install, and relaunch. Existing data, Memory history, capture settings, and Agent preferences are preserved.

## Validation

Validation covered Agent activation, model selection, failure recovery, rapid Agent switching, task recovery, capture lifecycle, menu bar behavior, performance and accessibility-sensitive refresh paths. The release workflow runs the complete core, adapter, packaging, benchmark, native-app, and signed-update checks on Apple Silicon and Intel before publication.

On a representative stored screenshot, background fast OCR completed in approximately 0.175 seconds versus 1.098 seconds for accurate recognition, while preserving searchable Chinese and English text.
