MyClip は作業画面を記録し、選択した AI エージェントで整理します。

- **Memory**：出典へのリンクを保った、検索可能な Markdown ノート。
- **Timeline**：デバイス上の OCR テキスト認識に対応したキャプチャ履歴。
- **Kanban**：タスク、進捗、日報・週報・月報。

キャプチャとノートは Mac に保存されます。AI による整理では、エージェントのクラウドサービスを利用する場合があります。**MyClip MCP** を有効にすると、AI ツールから保存済みのメモリを検索できます。

## インストール

**macOS 13 以降**、**Node.js 22 以降**、選択したエージェントのアカウントが必要です。

1. [Releases](https://github.com/section9-lab/MyClip/releases) から Apple Silicon または Intel 用の DMG をダウンロードし、MyClip を**アプリケーション**に移動します。
2. MyClip を開き、エージェントを選択して**使ってみる**をクリックします。
3. **画面収録**と**アクセシビリティ**の権限を許可します。MyClip を開いている間は、自動でキャプチャと整理を行います。

**設定**でキャプチャ範囲や除外アプリ、自動整理を変更できます。MyClip を終了するとキャプチャが停止します。

配布版は自己署名されており、公証されていません。初回起動が macOS にブロックされた場合は、[インストールのヘルプ](release-signing.md#installing-a-community-build)をご覧ください。
