MyClip은 작업 화면을 기록하고 선택한 AI 에이전트로 정리합니다.

- **Memory**: 출처 링크를 보존하는 검색 가능한 Markdown 노트.
- **Timeline**: 기기 내 OCR 텍스트 인식을 지원하는 캡처 기록.
- **Kanban**: 작업, 진행 상황과 일간·주간·월간 보고서.

캡처와 노트는 Mac에 저장됩니다. AI 정리는 에이전트의 클라우드 서비스를 사용할 수 있습니다. **MyClip MCP**를 켜면 AI 도구에서 저장된 메모리를 검색할 수 있습니다.

## 설치

**macOS 13 이상**, **Node.js 22 이상**, 선택한 에이전트의 계정이 필요합니다.

1. [Releases](https://github.com/section9-lab/MyClip/releases)에서 Apple Silicon 또는 Intel용 DMG를 다운로드하고 MyClip을 **응용 프로그램**으로 옮기세요.
2. MyClip을 열고 에이전트를 선택한 뒤 **시작하기**을 누르세요.
3. **화면 기록**과 **손쉬운 사용** 권한을 허용하세요. MyClip이 열려 있는 동안 자동으로 캡처하고 정리합니다.

**설정**에서 캡처 범위, 제외할 앱, 자동 정리를 변경할 수 있습니다. MyClip을 종료하면 캡처가 멈춥니다.

배포 버전은 자체 서명되었으며 공증되지 않았습니다. macOS에서 첫 실행을 차단하면 [설치 도움말](release-signing.md#installing-a-community-build)을 확인하세요.
