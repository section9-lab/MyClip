# Assets

Application interfaces are rendered from HTML/CSS. There are no full-window or sheet screenshots in the active assets.

- `assets/myclip.png`: existing MyClip project app icon.
- `assets/ui/onboarding-artwork.png`: original onboarding illustration from the project asset catalog.
- `assets/ui/*`: Agent and MCP client logos copied from the project asset catalog. Claude's crab is SVG geometry derived from the existing AgentCharacterDrawing implementation.
- `assets/macos/wallpaper.jpg`: locally bundled macOS Sonoma wallpaper, converted without grading.
- `assets/macos/*.png`: installed application icons and exported SF Symbols. Export script: `scripts/export-assets.swift`.
- `assets/share/*.png`: Feishu, Lark, DingTalk, WeChat and Slack icons exported from the installed apps with `scripts/export-assets.swift assets/share --share`. Gmail's SVG uses the same published geometry as `ReportShareView.swift`; Notion uses that view's web fallback monogram.
- `assets/vendor/gsap.min.js`: existing vendored animation runtime.
- `assets/recall.json` and `recall-data.js`: actual MyClip MCP responses to the fictional notes in `app-data.js`, generated by `scripts/recall.py`.

Timeline thumbnails are small HTML compositions of fictional work windows. Report, memory, task, permission, connection and usage content are demo fixtures. No personal library content, chats or account details are included.

Local real-app reference captures and retired bitmap demo assets are confined to ignored `snapshots/`. They are not loaded by the demo. Third-party icons and wallpaper remain their respective owners' artwork; their inclusion here is not a rights transfer.

The pointer's tip-anchored click mechanic was adapted from the HyperFrames registry oversized-cursor primitive at https://raw.githubusercontent.com/heygen-com/hyperframes/main/registry. Active media hashes and provenance are recorded in `.media/manifest.jsonl`.
