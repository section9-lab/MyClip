# Memory 检索：按日期版本对比与同类方案对照（2026-09-24）

口径见[评测协议](memory-benchmark-protocol.md)：问题原文调用一次检索，`limit=20`，原始会话语料（无链接），文件级计分。三个版本都用同一数据与同一计分代码，逐题结果可复算：

```bash
python3 -m benchmark.compare 09-20=benchmark/runs/2026-09-20/locomo-final 09-21=benchmark/runs/2026-09-21/locomo-2026-09-21 09-24=benchmark/runs/2026-09-23/r300-a-locomo
```

## 各版本为什么变化

- **09-20 → 09-21：词干归一化**。“Researching / research”“moved / move”归为同一词，多跳（26.9% → 34.1%）与跨会话受益最大；单跳有 1–2 题的边界抖动（94.3%）。
- **09-21 → 09-24：段落级打分**。长会话里只有一条发言回答问题时，整篇 BM25 被其余内容稀释；按最佳三段打分后，回答问题的发言能把整篇顶上来。LoCoMo 单跳 94.3% → 96.4%、MRR 0.758 → 0.793；LongMemEval 跨会话 69.4% → 75.2%。LoCoMo 多跳基本不变，原因是问题与证据的用词不重合（29% 的多跳题每条证据都与问题共享实词），见[召回改造评测](memory-recall-benchmark-2026-09-23.md)。
- **09-24 发言完整覆盖率下降、返回字数下降**：片段从每篇最多 3 段 × 1,600 字改为 2 段 × 300 字。文件排序不受影响；长发言与分散在多条发言里的证据不再被片段完整带出，需要时由 Agent 用 `memory_get` 读原文。

## 与同类方案对照

公开成绩分三类指标族，只有同族可以比较（详见[09-21 同类对照](memory-peer-comparison-2026-09-21.md)）。MyClip 目前只有检索召回的数字。以下同行数字于 2026-09-24 复核，与 09-21 记录一致。

**检索召回（与 MyClip 同族）**

| 系统 | 数据集与口径 | 数值 | 方法 |
|---|---|---:|---|
| Sibyl | LongMemEval-S 500 题，Recall@5 / Hit@5 | 96.96% / 100.00% | 向量 + 图混合检索，不用大模型抽取与重排 |
| MemPalace | LongMemEval-S，R@5 | raw 96.6%（500 题）；hybrid v4 98.4%（450 题保留集）；加大模型重排 ≥99% | raw 为纯向量；hybrid 另加关键词、时间邻近等启发式 |
| AutoMem | LongMemEval-S，Recall@5（实为 Hit@5 定义） | 97.00% | — |
| **MyClip 09-24** | LongMemEval-S 500 题，Recall@5 / Hit@5 | **92.77% / 97.40%** | 本地 BM25 + 段落级打分，无向量、无外部服务 |
| MemPalace | LoCoMo 1,986 题，会话 R@10 | raw 60.3%；hybrid v5 88.9% | 同上 |
| MyClip 09-24 | LoCoMo 1,532 道可计分题，文件级 recall@10 | 92.0% | 语料序列化不同（MemPalace raw 只索引用户发言），只作方向参考 |

MyClip 与 Sibyl 的 Recall@5 分类差距（09-24 − Sibyl）：用户事实 0.0、助手内容 0.0、偏好 −10.0、跨会话 −6.6、知识更新 −0.6、时间推理 −6.6，整体 −4.2 个百分点（09-21 时为 −5.3）。差距集中在偏好、跨会话、时间推理，这三类正是离线验证中加入向量后提升最大的类别（跨会话 75.2% → 83.5%，见[向量方案第十节](../../docs/memory-vector-retrieval-design-2026-09-23.md)）；向量方向已按决定停止。Hit@5 上 MyClip 97.40%，与 AutoMem（97.00%）、MemPalace raw（96.6%）同一水平，低于 Sibyl（100%）。

**问答准确率（MyClip 未测）**

第三方同套件 [ProsusAI MemEval](https://github.com/ProsusAI/MemEval)（LoCoMo 1,986 题，gpt-4.1-mini 阅读，gpt-5.2 评审）的 LLM 评审准确率：PropMem 82.3%、OpenClaw 72.5%、Hindsight 67.6%、Graphiti 57.3%、Mem0 49.7%、SimpleMem 47.8%、MemU 39.9%。厂商自报的 LoCoMo / LongMemEval 准确率（Zep 94.7% / 90.2%、Mem0 v3 92.5% / 94.4%、Hindsight 89.61% / 91.4% 等）的阅读模型、评审模型与题目范围各不相同，不能与检索召回混排，也不能互相排序。MyClip 要进入这一族，需要可用的阅读与评审模型，按 `benchmark_memory_qa.py` 跑全部题目。
