## Design Context

### Users
MyClip is for macOS users who want to turn their work in focused application windows into retrievable Markdown memories connected by Wikilinks. Codex and Claude are existing agents connected through ACP; MyClip owns capture, local storage, provenance, and the native interface.

### Aesthetic Direction
Use Apple Maps, App Store, and Settings as references: translucent native sidebar, quiet system-blue navigation, spacious reading surfaces, system typography, grouped settings, and compact standard controls. Support light/dark appearance and Reduce Motion. Knowledge and personal work are the main content; the sidebar contains only Timeline, Memory, and Task Board; connection and setup details stay in utility views.

### Menu Bar
Show one static paperclip in a standard square menu bar item. Use the native paperclip SF Symbol at 17 pt semibold with template rendering so its color follows the menu bar appearance. Keep the background transparent and open the main library window when clicked. Keep Agent status, connection details, and queue controls in the main window; do not show Agent avatars, status popovers, or hover animations in the menu bar.

### Principles
- Capture the focused window by default. If the user selects display capture, capture only the display containing that window. Describe the selected scope and enabled triggers accurately.
- Every knowledge entry leads back to its source captures.
- Status reflects actual capture, ACP, and persistent job state.
- Preserve useful work across failures; offer retry and cancellation clearly.
- Use real data or honest empty states. Sample content belongs only in an explicitly labeled preview.
- The task board follows personal work from candidate discovery through confirmation, execution, and completion. Keep a prominent New Todo action and a collapsible review section with three candidates per page. Expand evidence in place, separate the suggested status from the confirm action, and allow the latest review to be undone. AI advances confirmed tasks using fresh screenshot or Memory evidence; people confirm new tasks, review uncertain or backward changes, and can correct any status. Replace analytics charts with daily, weekly, and monthly work reports based on task history.
- Kanban columns use a pale gray-white Todo background, an orange half-circle with a pale orange In Progress background, and a blue checked circle with a pale blue Done background. Keep column headings fixed, scroll each column independently, and show no more than five equal-height task cards at a time.
- Keep work reports inside Kanban with only two English text tabs, Kanban / Reports, in a compact header with an underline for the selected tab. Do not add a separate page heading, date, or tab icons; place actions below the tabs. Use a white document on a pale gray canvas, a centered title and date, and numbered outlines grouped by project. Each project shows its own progress counts and status-marked items. Preserve period-specific edited drafts and copy the same outline / project / progress hierarchy.

### Memory Reading Experience
Keep the main sidebar limited to the three app modules. Memory has a separate secondary file navigator beside it, with an expandable native folder tree and actual folder and Markdown filenames. Read the selected document on the right. Include real empty directories and reflect external folder changes. Render every document directly from Markdown using Textual; do not substitute forms, cards, or special overview pages for file contents. Use Apple's native TextEditor for source editing with a rendered preview. Keep filename and actions in a compact toolbar; Markdown owns the document headings. Expose paths and revisions in file information. Avoid permanent technical metadata and empty source sections.

### Onboarding
Place native permission controls and default Agent selection on the left and a dreamlike courtyard oil painting on the right: ivory arches, a pale teal open door, clouds, and a reflecting pool. Detect installed supported Agents without activating them; save a default only after the user's selection connects successfully. Keep the two permission states explicit, use actual OS grants, and offer concise recovery guidance for grants that no longer match an updated application. Let the user finish Agent setup before entering the library. Preserve system typography and light/dark appearance. Avoid the centered stack of large gray cards.
